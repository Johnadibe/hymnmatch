# ACPPB Abu transcription report (hymns 176–224)

**Source folder:** `Hymn or Abu Snapped Pictures - second part` (86 JPEGs; hymns 129–175 are on the first 41 snaps, `18.08.09` → `18.08.55`; hymns 176–224 are on the remaining snaps `18.08.56` → `18.10.51 (1)`, **46 JPEGs used here** incl. `18.08.56`, which carries the end of 175 and the start of 176).
**Method:** printed hymn numbers + footer pages `(n)` + running section headers (not WhatsApp timestamps). All snaps are rotated on disk (90°, and five of them 180° — `18.08.57`, `18.09.04`, `18.09.19`, `18.09.41 (1)`, `18.10.48`); each was normalised to upright before reading. Several snaps were enlarged (crop/zoom) to confirm meters, scripture references and faint print.
**Range covered:** Abu **176 → 224** (footer pages **(143)** → **(185)**).
**Result:** every number 176–224 is present (**49 hymns, no numeric gaps**). **No hymn in 176–224 is partial** — each has its closing `Amen.` (or its final stanza) printed within the folder. All 46 snaps in this range were used; the 3 snaps not used for 176–224 (`18.10.47 (1)`, `18.10.47 (2)`, `18.10.48`) belong to Abu 225–229 (see §4).
**Page order ≠ timestamp order:** pages (172)–(175) are on `18.10.50`, `18.10.50 (1)`, `18.10.51`, `18.10.51 (1)` (shot *after* the later pages (176)–(183) on `18.09.53`–`18.09.57`), and pages (184)–(188) are on `18.10.46`–`18.10.48`. Hymn numbers/footers were used to order everything.

Orthography note: transcribed as printed (old ACPPB spelling with apostrophe elision, e.g. `n'`, `k'`, `nk'`). Dot-under `ọ` is used throughout; `ṅ` where a dotted ṅ is printed (e.g. `ọṅu` "joy"); `ụ` is not used (not visible in this block). The italic English line under each scripture quote is the printed tune/English title (`titleEnglish`). `hymnBookRefs` is exactly as printed; empty `""` means no `(A. n)` / `(U. n)` line is printed for that hymn. Indented continuation lines inside `lyricsIgbo` mirror the printed line indentation; `Kọrọs:—` marks a printed refrain. Verse numbers are sequential (`Verse N`) — where the book misprints a stanza number it is noted in §2.
